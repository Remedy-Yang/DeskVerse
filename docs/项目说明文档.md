# DeskVerse Studio 项目说明文档

更新日期：2026-10-18

适用范围：DeskVerse 当前仓库的浏览器端三维桌搭工作台及本机 Rodin 代理。实现依据为本次文档分支起点 `10463f5`（软件包版本 `1.5.0`）。

## 一、项目简介

DeskVerse Studio 是面向宿舍桌面规划的三维工作台。它希望帮助准备布置宿舍、添置桌面用品的学生，在购买或搬入前观察物品的尺寸关系、摆放效果及收纳空间。

用户可以使用内置模型、导入自己的 GLB，或在确认上传照片和消耗额度后调用影眸 Hyper3D Rodin 生成模型；随后输入真实厘米尺寸，调整物品的位置、朝向和大小，从自由视角、正交俯视或模拟坐姿视角观察，并保存布局或导出效果图。

项目将**外观生成**与**尺寸确认**分开：AI 生成模型用于提供外观，实物测量或经核实的商品规格用于校准。自动参考尺寸、OCR 候选和几何检查都不等于实测结论，也不构成购买适配、安全或人体工学保证。

## 三、功能说明

### 设计亮点与团队贡献

- **生成到规划形成闭环**：不止展示生成的模型，而是将 Rodin 资产接入尺寸校准、独立编辑、摆放检查、方案比较和成果导出；本机代理还实现照片提交、任务恢复、下载与场景导入。
- **面向宿舍真实操作场景**：桌柜、抽屉、柜门、椅子和上铺床垫可参与空间规划，将桌面搭配扩展到收纳与使用视角。
- **外观与尺寸分工明确**：用 AI 提供外观、用人工确认规格控制尺度，二维轮廓与三维视图同步反馈，避免将生成比例直接当作实物测量。
- **完整编辑与交付能力**：A/B 独立方案、撤销重做、轻量布局恢复、本地 OCR 和高清出图，让模型既能看，也能编辑、比较和交接。

### 功能清单

| 功能 | 当前仓库的实现 | 使用边界 |
| --- | --- | --- |
| 默认宿舍场景与资产库 | 默认载入桌柜、独立椅子和显示器；按类别提供家具、数码外设、照明和生活摆件，可重复添加普通物品；可导入官方默认桌搭 | 当前模型与参考规格不是学校实测认证；固定桌柜通过专用入口替换 |
| 本地模型导入 | 多选或拖入 GLB，解析嵌入资源；支持本地 Draco、Meshopt 和 KTX2 解码 | 单个 GLB 不超过 80 MiB；拒绝模型引用的外部图片 / 二进制 URI；具体压缩模型仍需核验 |
| 三维编辑 | 选择、移动、旋转、缩放、坐标输入；可主动开启贴合和吸附；支持撤销 / 重做 | 碰撞不回退用户操作；开启贴合 / 吸附仍按对应规则调整位置 |

| 二维与三维联动 | 二维俯视图选择和拖动；自由透视、桌柜线框、正交俯视；环绕、缩放和右键平移 | 俯视与线框不是 CAD 或精确工程图 |
| 摆放辅助检查 | 桌板边界、尺寸状态和占地冲突；部件 OBB 重叠、地面、收纳容量和路径提醒 | 保守几何近似，不是刚体物理；越界、重叠和超限只提醒、不强制拦截 |

## 四、运行与演示

### 启动

需要 Python 3 及支持 WebGL 的现代浏览器，推荐启用硬件加速的 Chrome / Edge。Windows 可双击仓库根目录的 `启动_Windows.bat`，或运行：

```powershell
py start.py
```

macOS / Linux：

```bash
python3 start.py
```

访问 <http://127.0.0.1:8000>；端口冲突时加 `--port 8002`，不自动开浏览器加 `--no-browser`。不要直接双击 `dist/index.html`。运行已交付页面无需 npm、构建或 CDN；模型与 OCR 文件须完整保留。

### 建议演示流程

1. 打开默认桌柜，添加一件资产或导入自己的 GLB，输入并确认实际尺寸。
2. 移动、旋转物品，对照三维视图和二维轮廓；移到越界 / 重叠位置，展示提醒不限制操作。
3. 切换坐姿观察、开合柜门与抽屉，演示收纳和撤销。
4. 在 A/B 中比较摆法，选择光照并导出 PNG；导出 JSON，再导入恢复当前方案。
5. 如演示照片生成，先说明联网、费用和输入图片权利；缓存结果或模拟接口必须明确标注，不冒充现场实时生成。

### 数据与隐私

- 普通 GLB 摆放、几何检查和尺寸图 OCR 在本机处理，不因使用这些功能而上传到 Rodin。
- 只有确认提交的建模照片会发送至 Rodin。网页本次输入的 Key 保留在本机服务进程内存；长期配置可放在环境变量或被忽略的 `.env`，不应提交密钥。
- 生成任务与模型保存在 `.deskverse/`；A/B 场景和撤销历史不自动持久化。刷新前应保存 JSON 和原始 GLB。
- 本机代理不是公网多用户服务，不能直接作为有账号隔离和鉴权的线上后端。
